# カクヨムテキストリーダー

原稿フォルダを開き、話ごと・版ごとに切り替えながら、カクヨムのリーダーと同じ見た目
（縦書き・明朝・ルビ・傍点）で読むためのビューアです。前の版との差分もその場で見られます。

## 起動

```
start.cmd
```

`http://127.0.0.1:7878/` が開きます。Node.js が必要です（`server.mjs` は外部に公開されず、
このフォルダのファイルだけを 127.0.0.1 に配信します）。

`index.html` をダブルクリックしても動きますが、そちらは **自動更新が効きません**（下記）。

## フォルダの構成

`drafts` のようなフォルダを開くと、話と版を自動で組み立てます。

```
drafts/
├ EP01/      V1.md V2.md … V6.md
├ EP02/      V1.md …
├ EP03/      V1.md …
└ current/   EP001.md EP002.md …
```

- `EP<数字>` という名前のフォルダ＝1話。中のファイルが版になり、自然順（V9 → V10）で並びます。
- `current` フォルダのファイルは、ファイル名の数字で対応する話に結び付き、**Current（最新）** として末尾に入ります。
- 他の名前のフォルダも、そのフォルダ名の1グループとして読み込めます。

## 版の切り替え

ヘッダーの「話」と「版」のセレクトで選びます。`[` `]` キーでも前後の版へ移動できます。
版を切り替えても読んでいた位置（割合）は保たれます。

## 差分

「差分」ボタン（`D` キー）で表示・非表示を切り替えます。設定は次回起動時も維持されます。

- **比較元** — 既定は「1つ前の版」。任意の版も選べます。
- Current は最新版と中身が同じことが多いので、その場合は自動的に1つ手前の版と比較します（比較対象はバーに表示）。
- **削除も表示** — 消えた文字を取り消し線で出すかどうか。隠した行には `⋯` の目印が残ります。
- **前の変更 / 次の変更**（`P` / `N` キー）で変更箇所だけを追えます。変更数もバーに出ます。

差分は段落単位で取り、書き換えられた段落はさらに文字単位で色分けします。
ルビや傍点は1つのまとまりとして扱うので、`漢字《かんじ》` が途中で割れることはありません。
空行の増減は変更箇所として数えません（送っても見るものがないため）。

## ファイルの更新

`start.cmd` で開いた場合、表示中のファイルが書き換わると自動で読み直します（画面左下が「自動更新中」）。
新しい版のファイルを追加した場合も、版のリストに自動で追加されます。
読んでいた位置は保たれるので、書き換えてはリーダーを見る、という往復ができます。

`index.html` を直接開いた場合はブラウザの制限でこれができず、「更新あり — 開き直してください」と出ます。
その場合は「フォルダを開く」でもう一度選び直してください。話と版の選択は復元されます。

## 読み上げ（VOICEVOX）

「読み上げ」ボタン（`V` キー）でバーが開きます。**先に VOICEVOX 本体を起動しておいてください。**
起動していなければ「VOICEVOX が起動していません」と出るだけで、他の動作には影響しません。

- 話者は VOICEVOX にある全スタイルから選べます。速さは 0.5〜2.0 倍。選択は次回も維持されます。
- 再生中の文がハイライトされ、画面外に出るとページが自動で送られます。
- 段落をクリックすると、そこから読み直します。
- 文単位で合成し、次の文を先に作っておくので、文の切れ目で止まりません。

読み上げ用のテキストは本文そのままではなく、次のように整えてから渡します。

| 本文 | 読ませる文字列 |
| --- | --- |
| `｜片瀬《かたせ》は` | かたせは（**ルビを読みに使う**） |
| `《《どうしても》》` | どうしても（傍点の記号は外す） |
| 差分表示中の削除された文 | 読まない |
| 差分表示中の追加された文 | 読む |

固有名詞にルビを振っておけば、そのとおりに読ませられます。

## 表示

| 機能 | 内容 |
| --- | --- |
| 書字方向 | 縦書き（右から左へページ送り）／横書き |
| 書体 | 明朝／ゴシック |
| 背景 | 白／セピア／夜 |
| 文字サイズ | 14〜30px |
| 行間 | 1.5〜2.6 |

## 対応記法

| 記法 | 書き方 |
| --- | --- |
| ルビ（親文字を明示） | `｜片瀬《かたせ》` |
| ルビ（漢字に自動で付く） | `薬缶《やかん》` |
| 傍点 | `《《どうしても》》` |
| 見出し（.md のみ） | `# 見出し` 〜 `### 見出し` |
| 区切り線（.md のみ） | `---` |

空行はそのまま1行の空きとして表示され、行頭の全角スペースも保持されます。

## キー操作

| キー | 動作 |
| --- | --- |
| `←` `→` | ページ送り（縦書きでは `←` が次） |
| `Space` / `PageDown` | 次のページ |
| `Home` / `End` | 最初／最後へ |
| `[` `]` | 前の版／次の版 |
| `D` | 差分の表示切替 |
| `V` | 読み上げの開始／一時停止 |
| `N` `P` | 次の変更／前の変更 |

ページ送りは1行ぶんの幅の整数倍で動くので、行が途中で切れません。

## 文字コード

UTF-8（BOM の有無を問わず）、UTF-16、Shift_JIS を自動判定します。

## 制限

- 青空文庫記法のうち、対応しているのはルビと傍点のみです。
- フォルダの探索は3階層までです。
- 読み上げは VOICEVOX のみに対応しています。VOICEROID はブラウザから直接操作できないため使えません。
- 読み上げのハイライトには CSS Custom Highlight API を使います。非対応のブラウザでは色が付かないだけで、読み上げ自体は動きます。
